Mariem Elkomy — AI Portfolio Website
==================================

1) افتحي index.html في Chrome عشان تشوفي الموقع.
2) لتغيير المشاريع: افتحي projects.js بأي محرر نصوص.
   - title: اسم المشروع
   - category: التصنيف
   - description: الوصف
   - tags: التقنيات
   - link: رابط GitHub أو Colab أو فيديو ديمو (لو متاح)
   - لإضافة مشروع: انسخي عنصر كامل داخل القائمة وغيري id وبياناته.
3) لتغيير LinkedIn والإيميل: افتحي index.html وابحثي عن:
   https://www.linkedin.com/  و  YOUR_EMAIL_HERE
   ثم ضعي روابطك الحقيقية.
4) الشهادات في index.html؛ يمكن إضافة شهادات أو تعديلها.
5) لنشر الموقع مجانًا: اعملي GitHub repository جديد اسمه portfolio، ارفعي الملفات الثلاثة
   index.html و style.css و script.js بالإضافة إلى projects.js، ثم
   Settings > Pages > Deploy from a branch > main / root > Save.
   انتظري بضع دقائق لحد ما رابط الموقع يظهر.
6) لتحديث الموقع بعد النشر: عدّلي الملفات وارفعيها على نفس المستودع.

ملاحظات:
- لم تتم إضافة رقم الهاتف أو الإيميل أو الـCV حفاظًا على خصوصيتك؛ أضيفي نسخة CV مخصصة للنشر بعد مراجعة بياناتها.
- ملفات المشاريع الأصلية لم تُنشر ضمن الموقع. يوجد مكان لإضافة روابطها لاحقًا.
- ملف ass.11.rar لم نتحقق من محتواه بعد، ولذلك لم نضع له وصفًا قد يكون غير دقيق.
- Untitled3 (1).ipynb و Copy_of_Untitled3.ipynb يبدوان نسختين من نفس المشروع، فتم عرضه مرة واحدة.
- بيانات الشهادات يمكن مراجعتها وتعديلها قبل النشر.
